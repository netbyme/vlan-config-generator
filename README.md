# vlan-config-generator

A Python tool that generates ready-to-paste Cisco IOS VLAN configuration commands automatically.

## What it does

- Takes a list of VLANs with IDs and names
- Generates complete Cisco IOS configuration commands
- Output can be copied directly into a Cisco switch
- Saves time and eliminates manual typing errors

## Why this matters

Network engineers configure VLANs manually on every switch — one typo can break connectivity for an entire department. This tool generates the commands automatically and consistently every time.
